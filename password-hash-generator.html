Use it in your code

Your app should hash each password when a user signs up and check it when they log in. Here is how to do that for the algorithm you chose.

About

Passwords should never be stored in a database as plain text or encrypted with a key that could be stolen. Store a one-way hash instead: when a user logs in, hash what they typed and compare it with the stored hash. This tool makes those hashes with bcrypt, Argon2id or PBKDF2, which are built to be slow and salted, so leaked hashes are very hard to crack. Each hash includes its own random salt and settings, so the same password gives a different hash every time. Everything runs in your browser using WebAssembly and it never leave your device.
