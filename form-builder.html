About

Build an HTML form without writing code. Add rows, split each row into 1 to 12 columns, and choose a field for every column: text, email, number, password, phone, textarea, select, checkbox, radio, file upload, colour picker or calendar. Set labels, placeholders, options and validation rules such as required, length, number range, date range, pattern and allowed file types, then try the live preview. Copy the Bootstrap 5 HTML with its validation script, or download a ready-to-open page. Everything runs in your browser and your form is saved on this device.
