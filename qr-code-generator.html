About

Make a QR code for a website link, plain text, Wi-Fi login, email, phone call, text message, WhatsApp chat or contact card. The code updates as you type. Change the colours, choose square, rounded or dot-shaped modules, set the error correction level and add your logo in the centre. When you add a logo, error correction is set to High so the code still scans with part of it covered. Download a PNG up to 2048 pixels wide or an SVG that stays sharp at any size for print. Dark codes on a light background scan best, so the tool warns you if your colours are too close. The QR codes are static and never expire, and everything runs in your browser, so nothing you type is uploaded.
