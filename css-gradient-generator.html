About

Create CSS gradients for backgrounds, buttons and cards without writing the code by hand. Choose a linear, radial or conic gradient, then click the colour bar to add colours, drag the handles to move them, and pick each colour and its opacity. Set the angle by dragging the dial or typing a number, choose the centre of radial and conic gradients, or make the pattern repeat to create stripes. The live preview shows exactly what you get, and the CSS updates as you go, with a solid colour fallback for very old browsers. Start from one of the presets or press Random for ideas, then copy the CSS or download the gradient as a PNG image for use in designs. Everything runs in your browser, so your css gradient generator never leave your device.
