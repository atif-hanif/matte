    About

    Use Random mode to make lists of made-up email addresses for testing sign-up forms, filling demo databases or creating sample data. Choose a username style, a domain and how many you need, then copy them or download a .txt or .csv file. Use From a name to list the address patterns companies use most, such as john.smith, jsmith and smith.john, which helps when you need to guess someone's work address. Use My username to type the username you want and see it on each domain, along with variations such as yourname.official or yourname2026 in case it is taken. The addresses are generated only from patterns, so they are not real inboxes and may belong to real people if you use a public domain. For testing, keep the default example.html, which is reserved and never delivers mail. Everything runs in your browser.
